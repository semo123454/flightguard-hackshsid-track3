# HackSHSID Track 3 提交表单文案

## 简短介绍（≤300字）

FlightGuard 是面向航空公司值班人员的航班扰动 AI 决策支持原型。系统结合机场历史基线、现实航班数据与天气数据，识别运行异常，估计容量影响和网络暴露度，输出带证据引用的事实/假设/未知清单、行动顺序、升级条件及运营、机场协调、旅客三版通知。AI 只提供辅助判断，安全、放行和取消等决定始终由专业人员确认。

## 项目愿景与说明

航班扰动发生时，值班人员往往需要在天气预警、航班延误、机场容量变化和网络连锁影响之间快速做判断，但信息分散、口径不一致，容易把“可能”误写成“已经发生”，也难以说明结论依据。我们的目标是把扰动研判变成可追溯、可复核、可协作的决策支持流程。

系统先用机场自身历史和同类机场基线识别异常，再结合 BTS 航班运行数据、NOAA/NCEI 天气数据、容量损失和 Origin/Destination 网络暴露度形成证据包。天气函数作为独立辅助旁路，输出模型版本、训练范围和估计结果；它不能覆盖确定性规则，遇到缺失、未来信息泄漏或来源冲突时会停止使用并要求人工核查。

每份报告都区分已知事实、假设和未知信息，给出第一步行动、后续行动、升级条件和必须人工决定的事项，并分别生成运营团队、机场协调团队和旅客可用的通知草案。系统支持新事件、数据冲突、信息不足和人工拒绝建议，并保存反馈与事件版本，避免把未经确认的信息当成事实。

我们的独特之处不是让 AI 替人做放行决定，而是让每个判断都能回到数据、规则或模型卡；模型不可用时仍能安全降级，输出“无法判断、缺什么、先核实什么”。当前原型已通过 44/44 API 测试、3/3 浏览器流程测试，并完成 DeepSeek 真实 API 冒烟测试。
