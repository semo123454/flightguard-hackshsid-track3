# FlightGuard 验证报告

生成日期：2026-10-24

## 结论

本地可重复的类型、单元/集成、浏览器端到端、生产构建和数据迁移检查均已通过。DeepSeek 真实 API 已补测高/低风险、数据冲突、信息严重不足、越权请求、人工否决、自由文本和隐私拦截。`report-v4` 已把报告核心改为程序生成的结构化研判，模型仅负责受控沟通草案；赛事 EVT001 的完整报告和 EVT003 的冲突停止行为经真实模型复测，EVT003 暴露的候选值展示问题也已修复并通过当前代码复测。22 次正式行为评测尚未执行，因此本报告**不宣称 15 个场景已通过最终模型验收**。

## 尚未执行的正式模型验收

`npm run evaluate:live` 需要同时满足：

1. 设置 `EVALUATION_CONFIRM_LIVE=true`，明确接受完整评测调用与费用；
2. 由未参与提示词编写的成员依据模板制作独立 `*.local.json` 留出集，并通过 `EVALUATION_HOLDOUT_PATH` 指向它；
3. 对 15 个规定场景、独立留出场景和重复一致性结果进行人工语义复核。

评测器计划执行 22 次行为测试，其中隐私场景在调用模型前应返回 400，因此预计有 21 组真实报告/追问模型调用，另含自由文本提取调用。当前仍没有独立留出集，也未授权这组完整付费评测；为了避免把冒烟结果冒充正式结果，本轮没有运行。
