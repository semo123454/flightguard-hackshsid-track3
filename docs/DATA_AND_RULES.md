# 数据、证据与规则说明

## 数据范围与血缘

系统导入赛事提供的本地 JSON 镜像，包含 8 个模拟机场、月度运行基线、年度画像、天气背景、来源登记和 12 条规则。导入器：

- 为空值保留 `null`，不转换成 0；
- 校验年月、比例、天气单位、来源外键和唯一键；
- 为既有机场使用固定 ID，新机场使用名称哈希生成稳定 ID；
- 保留工作表行定位，并登记数据集 SHA-256；
- 将发布日期规范化为带时区的 ISO 时间；
- 对明确标记缺失的天气记录保持缺失状态，即使单元格仍有数字；
- 重复导入同一数据集不增加记录。

每条报告证据包含稳定 ID、类别、来源、记录定位、数据版本、时间、核验状态和模拟标记。

## 前 12 个自然月基线

参考月 `YYYY-MM` 不参与自身基线。系统只查询参考月之前固定的 12 个自然月窗口，不会在缺月时使用更早记录补足。报告同时列出：

- 实际样本月数；
- 覆盖起止月；
- 缺失月数；
- 指标名称和粒度；
- 来源与记录定位。

`scheduled_completion_ratio` 与 `airport_release_normal_ratio` 分开计算。只有同指标、同为月度、且当前观测期间等于参考月时才计算百分点差；日内描述或错期数据只作为背景。

异常边界为当前按计划完成比例比历史均值严格低于 5 个百分点。恰好 `-5.00 pp` 不触发异常。

## 确定性规则

- 未知值保持 `null`，不会当成否定或安全证据；
- 来源冲突或未登记/未核验来源优先触发停止条件；冲突时不选择任一数值计算差值；
- 高风险至少需要两个独立信号及两个不同的已核验来源；
- 天气风险、运行压力、正式状态和现场资源分别构成规则信号；
- 低风险仅表示当前有效信息范围内未触发风险信号，不代表已确认安全；
- 所有取消、放行、调度、维修、赔付和正式发布均保留给人工决定；
- 模型只能解释服务器给定的风险和允许动作，不能新增执行动作。

规则模板在语言模型关闭或失败时仍生成证据、信息缺口、核查方向和三类待审核草案。

## 人工反馈与修订

接受、修改和拒绝都追加反馈记录，不覆盖原报告。人工可以同时提交：

- 补充事实文本；
- 四个确定性字段的确认更新：天气风险、运行压力、正式延误、资源充足。

有新增事实或确认字段时，系统在同一事务中创建不可变事件新版本，并以 `HUMAN-CONFIRMED` 记录来源。内部确认来源不能由普通事件接口伪造。新分析绑定新版本并关联父报告；原报告的风险、内容和反馈仍可查询。

## 天气旁路

当前配置会加载现实数据天气旁路并返回带模型卡信息的辅助估计；若关闭或模型不可用则返回 `not_configured` / `estimate: null`。接口会校验完整输入、来源发布时间和输出契约：

- 缺失、越界、未验证或未来信息泄漏时不返回估计；
- 估计作为 `evidence.kind=estimate` 单独展示，不计作第二个独立来源；
- 与已核验同指标月度事实相差超过 5 个百分点时，估计从建议生成上下文移除，并要求人工复核；
- 天气结果不会覆盖确定性风险或停止条件。
