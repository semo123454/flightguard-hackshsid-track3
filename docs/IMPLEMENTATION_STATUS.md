# FlightGuard 实施状态

更新日期：2026-10-24

## 1. 核心助手

状态：**代码完成，规则模式、本地流程及 DeepSeek 真实 API 冒烟已验证；独立留出集正式验收待外部条件。**

已实现：

- npm workspaces、TypeScript strict、Fastify 5、React/Vite、Ajv 与 SQLite；
- 四套核心 JSON Schema、三态布尔、相互独立的完成率与正式延误状态；
- 四个编号迁移、WAL、外键、幂等导入、不可变事件版本、分析与人工反馈留痕；
- 固定前 12 个日历月历史窗口、严格低于 −5 个百分点边界、时间粒度可比性、来源冲突与停止条件；
- 稳定证据 ID、数据/规则/提示词/事件版本、30 条上下文上限及规则证据保护；
- OpenAI-compatible Responses API 适配器、OpenAI/DeepSeek 一等配置、可控思考强度、提取/报告/追问三任务、每任务最多一次修复、严格输出校验、可关闭缓存、并发与每日 token 预算；
- 事件、修订、分析、追问、反馈、人工确认字段、17 字段导出与健康接口；
- React 事件输入、报告、证据、历史图表、三类草案、追问、反馈、历史与设置页面；
- 隐私信息在持久化和模型调用前拒绝；内部来源标识不能由普通客户端伪造；
- 规则、API、模型故障、天气和浏览器完整流程验证。

DeepSeek `deepseek-flash` 已完成真实结构化直连、高/低风险、数据冲突、信息严重不足、越权请求、人工否决修订、证据追问与自由文本冒烟。`report-v4` 将风险结论、当前值、本场历史、同类机场、已知/未知和规则依据改为程序生成，模型仅生成受控沟通草案。赛事 EVT001 与 EVT003 复测均为真实 `llm` 模式，引用缺失为 0。完整 `npm run evaluate:live` 仍要求独立编写的留出集、明确付费确认和人工语义复核，才能关闭最终验收项。

## 2. 冗余接口

状态：**完成并已验证。**

- 模型关闭时，结构化事件仍可生成规则报告、回答追问、接受反馈和导出；
- 模型超时、格式错误、错误证据引用或受限动作会修复一次，仍失败则回退；
- 天气函数关闭、未验证、缺数据、越界、未来信息泄漏或技术失败时，核心流程继续；
- 天气结果与已核实同指标冲突超过 5 个百分点时停止使用估计结论；
- 天气模块连续三次技术失败后熔断 60 秒；
- 并发幂等请求合并，事件版本冲突返回 409，本地模型并发/预算拒绝返回 429。
