## 尚未关闭的必需验收门槛

剩余工作需要独立评测人员和明确的完整付费评测授权：

1. 由未参与提示词编写的成员制作独立留出集；
2. 设置 `EVALUATION_CONFIRM_LIVE=true`，明确允许完整评测产生调用费用；
3. 执行 `npm run evaluate:live`；
4. 人工检查语义正确性、一致性和不可接受失败，而不只看 JSON/规则断言。

在以上四项完成前，项目可使用规则模式或已经冒烟验证的 DeepSeek 模型模式运行，但不能声称 22 次正式模型评测已经通过。
